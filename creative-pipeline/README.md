# 소재 확장 파이프라인 (우수소재 복제)

광고 진단의 🏆 확장 추천 소재를 같은 구조로 복제해 신규 제품 소재를 만드는 파이프라인.
이 폴더만 있으면 대화가 날아가도, 다른 사람이 Claude에게 맡겨도 똑같이 재현 가능.

## 사용법 (마케터용 — 3단계)

1. 광고 진단 → 🏆 확장 추천 → **[확장 브리프 복사]**
2. Claude 채팅에 붙여넣고 빈칸 채우기 (확장 제품명 / 소구포인트 / 오퍼 / 비율·변형수)
3. **제품 누끼 PNG**만 첨부 → Claude가 변형 N종 제작
   (폰트는 첨부 불필요 — 아래 구글 드라이브 폰트 폴더에서 Claude가 직접 가져옴)

## 폰트 저장소 (구글 드라이브)

- 폴더: **Installable_Fonts_24_Flat** — https://drive.google.com/drive/folders/1WxOFcO2x4b6SaH1bQ34mxYv9BS052GbB
- Claude가 드라이브 커넥터로 직접 다운로드 (`'1WxOFcO2x4b6SaH1bQ34mxYv9BS052GbB' in ancestors` 검색 → download_file_content)
- 상업용 무료 폰트 24종 (Paperlogy·A2Z·에스코어드림·어그로체·세방고딕 등)
- 새 폰트는 이 폴더에 추가만 하면 됨

## Claude 실행 절차 (Claude가 읽는 부분)

1. **우수소재 구조 분해**: 브리프의 우수소재 썸네일을 보고 레이아웃 DNA 추출
   (예: 상단 성분 뱃지 → 초대형 후킹 → 보조라인 → 제품 대형 배치 → 우하단 원형 뱃지 → 하단 오퍼바)
2. **배경 생성**: Higgsfield MCP `generate_image` (model: gpt_image_2_6, 1:1)
   - 프롬프트에 반드시: "No text, no letters, no logo, no product, no people" + 중하단 제품 자리 비우기
   - 실사(photorealistic/cinematic) 키워드 필수 — 플랫 벡터 느낌 금지
3. **합성**: 이 폴더의 `render.js` 사용 (Playwright 렌더, 1000×1000 @2x = 2000×2000)
   - 제품: 사용자가 첨부한 **실제 누끼 PNG** → `assets/can.png` (AI 생성 제품 금지 — 라벨 왜곡)
   - 배경: `assets/bg1.jpg`(V1·V3), `assets/bg2.jpg`(V2)
   - 폰트: `assets/fonts/` — 메인 후킹=Paperlogy 9 Black, 서브·뱃지·오퍼바=A2Z (사용자 첨부)
4. **검수**: 렌더 결과를 직접 보고 — 텍스트 겹침 / 줄바꿈 깨짐 / 뱃지 안 글자 넘침 확인 후 전달

## 확정 디자인 공식 (2026-11-20 바이퍼 샘플링에서 확정)

| 요소 | 값 |
|---|---|
| 메인 타이틀 | Paperlogy 9 Black · **#EDFF94** · 플랫(스트로크 없음) · skewX(-8°) |
| 가독성 | 헤드라인 존 뒤 다크 블러 패널 (SVG ellipse #000 52% + blur 48) |
| 서브/뱃지/오퍼바 | A2Z 폰트 (9 Black / 8 ExtraBold) |
| 배경 | AI 실사 (그린 플라즈마·번개폭풍) + 입자·그레인 FX |
| 제품 | 실제 누끼 + 그린 글로우 drop-shadow |
| 구성 N종 | V1 가격파괴 / V2 성분스펙 / V3 맛·제로슈거 (소구 분리) |

## 카피 규칙

- 성분 수치는 **제품 라벨에 실제 표기된 것만** (예: 아르기닌 4,000mg — 캔 라벨 근거)
- 구성 수량(24캔 등) 반드시 노출 — 가격만 쓰면 단품 가격으로 오해
- 과대광고 금지: 치료·완치·의약품 효능 표현 불가 / 체중 감량 암시 회피
- 극단적으로 짧고 강한 구어체 (삼대오백 톤)

## 제약 (중요)

- Claude 작업 환경은 외부 사이트 직접 다운로드 불가 → **힉스필드 생성 결과는 위젯에서 다운받아 채팅에 첨부**해야 로컬 합성 가능 (구글 드라이브는 커넥터라 예외적으로 직접 접근 가능)
- 폰트 파일은 라이선스 문제로 저장소에 올리지 않음 → 위의 구글 드라이브 폰트 폴더 사용

## 크레딧/비용 구조

- 이미지 소재: 힉스필드 gpt_image_2_6 배경 생성 **0.25크레딧/장**이 전부. 타이포 합성·수정 재렌더는 0크레딧 (Claude 사용료만)
- 영상 소재: 힉스필드 Marketing Studio 템플릿 리메이크 약 **70크레딧/건** — 크레딧의 주 소모처
- 생성한 배경은 재사용 가능 — 같은 제품군이면 배경 재생성 없이 0크레딧으로 변형 생산
- 영상 소재는 힉스필드 Marketing Studio 템플릿 리메이크(제품 교체) 방식 사용 — 별도 플로우

## 사후 관리 루프

새 소재 집행 후 광고 진단에서:
- ⚠ 노출 못 받음(세트 점유율 <10%) → 단독 세트 분리 검토
- 분리 후에도 손익분기 미달 → OFF 검토

## 🎬 체험단 실촬영 편집 영상 (2026-11-23 샘플 확정)

실행 환경: **힉스필드 샌드박스** (네이버 접속 가능 — Claude 컨테이너는 불가). 스크립트: `review-video/`

1. `crawl.py` — 네이버 블로그 검색(제품명 키워드 3종 × 2페이지) → 모바일 글 열어 영상(vid/inkey)·GIF 추출
   - **체험단 필터**: 본문에 `제공받|원고료|체험단|협찬|소정의` 있는 글만 사용 (내돈내산·일반 후기 제외)
   - 영상은 `apis.naver.com/rmcnmv/rmcnmv/vod/play/v2.0/{vid}?key={inkey}` → 최고화질 mp4
   - 출처용 블로그명: `m.blog.naver.com/{blogId}` 의 `<title>` (예: "책 읽는 하루")
2. 컷 선정: 1초 간격 콘택트시트로 확인 → 4컷 × 3.5~4초 = 15초 (세팅 → 개봉 → 따르기/사용 → 제품 단독+오퍼)
3. `ov.js` — Playwright로 투명 PNG 자막 오버레이 생성 (상단 2줄, 키워드 컬러 하이라이트, 우하단 출처, 마지막 컷 원형 오퍼 뱃지)
4. ffmpeg로 컷별 overlay → concat → 무음 트랙(음악은 메타에서) → 1080×1920 15초

- 폰트: 샌드박스는 드라이브 접근 불가 → Paperlogy는 공개 CDN(`cdn.jsdelivr.net/gh/projectnoonnu/2408-3@1.0/Paperlogy-9Black.woff2`)에서 받음. A2Z는 공개 CDN 없음 → 영상 자막은 Paperlogy 사용
- 엔딩: 기본 없음. 필요 시 마지막 컷 오퍼 카드 or 로고플레이 (로고: 드라이브 https://drive.google.com/drive/folders/1pjVbsHbwLCc1bYELzR5hxRroMlz7OTwx)
- 결과물 전달: 샌드박스에서 media_upload → PUT → media_confirm → 힉스필드 미디어함
